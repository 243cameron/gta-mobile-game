# GTA Mobile Prototype

A lightweight mobile-friendly open-world action game prototype inspired by GTA-style gameplay.

Features:
- Top-down city map
- Run on foot and drive a car
- Touch controls for mobile devices
- NPC pedestrians and police chase system
- Cash pickups and mission objective
- No external dependencies

Quick start:
1. Open the repo in a local web server
2. Run: `python3 -m http.server 8000`
3. Open: `http://localhost:8000`

Controls:
- Desktop: WASD or Arrow Keys to move, Space to enter/exit car, Shift to boost
- Mobile: Use the virtual joystick and buttons on screen

Goal:
- Collect cash pickups and survive the police chase while driving around the city.

This is intentionally a compact prototype to give you a playable starting point for a bigger mobile game project.
